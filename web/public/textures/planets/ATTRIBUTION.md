# Planet texture credits

The 2K planetary maps in this folder were supplied from Solar System Scope's
free planet texture pack: https://www.solarsystemscope.com/textures/. Credit
Solar System Scope and retain the CC BY 4.0 license when redistributing these
maps: https://creativecommons.org/licenses/by/4.0/.

The available maps are Sun, Mercury, Venus atmosphere, Mars, Jupiter, Saturn,
and Neptune. No Uranus surface map or Saturn ring map was supplied; Uranus
retains the procedural fallback and Saturn's ring is generated locally.

`2k_neptune_roulette.jpg` is a modified version of Solar System Scope's `2k_neptune.jpg`
(contrast raised, sharpened, horizontal streak noise overlaid with ffmpeg) for
the planetary roulette; same CC BY 4.0 license and credit.
