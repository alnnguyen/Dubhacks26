# Planetary body textures

1K equirectangular maps used by free-flight explore (`/?explore=1`).

| File | Source | License |
|---|---|---|
| moon_1k.jpg | three.js examples (`examples/textures/planets/moon_1024.jpg`) | three.js MIT; imagery NASA LRO / public domain |
| mars_1k.jpg, venus_1k.jpg, jupiter_1k.jpg, mercury_1k.jpg | [threex.planets](https://github.com/jeromeetienne/threex.planets) map images | NASA public-domain planetary mosaics redistributed for demos |

Earth day/night/clouds remain under `../earth/` (Solar System Scope / NASA — see that folder’s attribution).

Gameplay positions are compressed (not real AU). UI labels this as a gameplay-scale solar system.
