# UI button sounds

Hover behavior and MP3 samples supplied by the user in `Downloads/button-handoff.zip`. Matching WebM alternatives and source declarations are retained from the user-supplied `space-battles-assets/sfx` pack.

- `ui_tap_a`: Kenney Interface Sounds, `select_001.ogg` — CC0 1.0.
- `ui_tap_b`: existing shared UI tick; see the parent sound manifest.
- `ui_back_a`: Kenney Interface Sounds, `back_001.ogg` — CC0 1.0 (kept on disk; gameplay back now uses `click_h`).
- `click_h`: user-supplied back-button click (`Downloads/click_h.mp3`).

Source declaration: https://kenney.nl/assets/interface-sounds . These declarations come from the supplied asset manifest; no new independent licensing audit was performed.
